# 第一章：卖货（概论）

> **结论**：卖货是离美元最近、门槛最低的一条路。数字产品零成本起步适合新手先赚到第一刀；平台电商天花板高但政策风险大。**先看账，再选路。**

## 先看账（本章总览）

| 路径 | 启动成本 | 每周时间 | 天花板 / 中位数 / 新手首单 | 下限 | 证据 |
|---|---|---|---|---|---|
| Etsy 数字产品 | ~$0 | 5h | $2000+ / $150 / 约30天 | 1–2个月零单；最坏亏几十刀上架费 | B |
| POD 按需定制 | ~$0 | 8h | $5000+ / $200–500 / 30–60天 | 利润薄（实得约23%），测款沉没时间 | B |

| 独立站 DTC | $1000+/月 | 15h+ | 最高 / 低 / — | 广告烧光，死在获客上 | B |

## 路径 1-1：Etsy 数字产品（模板 / 壁纸 / 工作簿 / 打印品）

> **结论**：零成本起步，适合审美好的新手；中位数 $150/月，天花板 $2000+/月。值得做，别指望暴富。

**先看账**
- 成本：上架 $0.2/个 + 交易费 6.5% + 支付处理约 3%+$0.25；每周 5 小时
- 技能：必需——审美、选品耐心；加分——英语文案、Etsy SEO
- 收益：天花板 $2000+/月｜中位数 $150/月｜新手首单约 30 天
- 上限：多店矩阵 + 爆款可到 $5000+/月
- 下限：1–2 个月零单是常态；年销过 $1 万被强制扣 12–15% 站外广告费；最坏亏几十刀上架费
- 口径：$/月为主｜证据：B

**怎么做**（5 步）
1. 选 niche：在 Etsy 搜销量/评价/价格，建选品表（Top 10 法）
2. 做出来：Canva + AI，一周先做 5 个 listing 别做 1 个
3. 写英文标题：埋长尾关键词（用 eRank / Everbee 查，别凭感觉）
4. 上架测：主图 3 秒测试——和类目 Top 10 并排放，能被注意到再上
5. 堆产品线：靠裂变变体（颜色/尺寸/主题）把 1 个想法变成 20 个 listing

**你会碰到的问题**
- **Q：新手第一个月没单正常吗？**
  A：正常，多数新店都这样。先检查三处：主图 3 秒测试、标题有没有长尾词、是不是只上了 1 个 listing。（关键词：etsy no sales first month）
- **Q：定价 $1.99 打价格战行不行？**
  A：不行，死得最快的一种。Etsy 买家为"调好的成品"付费，不为便宜买单；$1.99 连广告税都覆盖不了。
- **Q：中国身份证能开 Etsy 店吗？**
  A：Etsy Payments 未覆盖中国大陆，开店和收款方案要走第三方（政策常变，**动手前先查 Etsy 官方 Seller Handbook**，本条 2026-10-08 标为需核验）。
- **Q：数字产品和 POD 先做哪个？**
  A：先做数字产品。零边际成本、试错便宜；POD 要处理实物履约和退货，心智负担重一倍。

## 路径 1-2：POD 按需定制

> **结论**：零库存卖实物，适合有作图能力的人；利润比数字产品薄一半，胜在客单价高。

**先看账**
- 成本：$0 库存；单件代工+运费是大头；每周 8 小时
- 技能：必需——选品、作图；加分——英语、社媒引流
- 收益：天花板 $5000+/月｜中位数 $200–500/月｜新手首单 30–60 天
- 上限：爆款 + 多平台（Etsy + 独立站）放大
- 下限：利润率只有约 23%（Arriell 实账）；测款沉没的是时间；退货纠纷
- 口径：$/月为主｜证据：B

**怎么做**：选 niche → AI/设计出图 → Printful/Printify 自动履约 → Etsy 上架 → 测款加量。

**你会碰到的问题**
- **Q：POD 和数字产品哪个利润高？**
  A：数字产品。POD 每单都要分钱给代工厂，Arriell 实账利润率 23%，数字产品接近 90%。
- **Q：AI 生成的图能商用吗？**
  A：看工具授权条款。Midjourney 付费版可商用，各平台条款会变，上架前查一次。（需核验）

**参考资料**：YouTube Arriell Johnson（同上）；Printful/Printify 官方文档（A 级，一手）

## 路径 1-3：TikTok Shop（美区为主）

> **结论**：天花板最高、节奏最快的一条，但政策风险和资金门槛也是最高的。新手别从这里开始。

**先看账**
- 成本：保证金 + 备货 + 达人寄样 + 广告，$2000 起步是常态；每周 20h+
- 技能：必需——选品、执行力、资金周转；加分——英语、短视频、达人 BD
- 收益：天花板很高｜中位数波动大｜新手首单看执行力
- 上限：单品爆单月入数万刀（幸存者）
- 下限：政策一变店就没；库存砸手里；**2024–2025 的 SOP 都要重核政策**
- 口径：$/月 + 风险（高）｜证据：B

**怎么做**：开店过审 → 选品备货 → 短视频测款 → 达人带货 → 直播冲量 → 广告放大。

**你会碰到的问题**
- **Q：美区现在还能进吗？**
  A：能，但规则变得快。任何教程（包括下面两个 GitHub repo）都要对照 TikTok Shop 官方 Seller Center 重核一遍，过期 SOP 等于毒药。
- **Q：没货能在 TikTok Shop 卖吗？**
  A：无货源是平台重点打击对象（见 2026-10-06 无货源打法 verdict：原版已死）。别碰。

## 路径 1-4：独立站 DTC（Shopify）

> **结论**：利润最高、品牌是自己的，但获客是地狱难度。有预算、有投放/SEO 能力再来。

**先看账**
- 成本：建站 $30/月起 + 广告预算，$1000/月以下测不出结论；每周 15h+
- 技能：必需——投放或 SEO、资金；加分——品牌、设计
- 收益：天花板最高｜中位数低（多数死在获客成本）
- 下限：广告烧光，$3000 买个教训是常见结局
- 口径：$/月 + 风险（中高）｜证据：B

**怎么做**：建站 → 广告/网红/SEO 获客 → 邮件复购 → 品牌沉淀。

**你会碰到的问题**
- **Q：独立站和 Etsy 先做哪个？**
  A：Etsy。独立站没有自带流量，Etsy 有。先在 Etsy 跑通选品和转化，再把利润搬到独立站做品牌——Matt James 就是这条路。

## 常见问题 Q&A（全章通用）

- **Q：卖货第一步到底先干什么？**
  A：先算账。打开 Etsy 费率页 + 本章"先看账"表，选一条"亏得起"的路，再谈执行。
- **Q：英语不好能卖货吗？**
  A：能。Etsy 标题和客服用 AI 写，数字产品不怎么需要沟通；TikTok Shop 美区和独立站对英语要求高一档。
- **Q：需要先注册美国公司吗？**
  A：Etsy/POD 不用，先跑通再说；TikTok Shop 美区和 Stripe 收款才涉及公司主体。详见基建章（后置）。
- **Q：每天要投入多少时间？**
  A：数字产品 5h/周起步；TikTok Shop 20h+/周是常态。时间不够就别碰重运营的路。
- **Q：$100/月现实吗？**
  A：数字产品/POD 现实（中位数就覆盖）；TikTok Shop 和独立站要么远超、要么归零，方差极大。

## 心法（本章 4 条，判断 + 反例 + 检查）

1. **「先卖，再进货」**——库存是最大的坑。反例：品牌独立站靠品质和时效，纯预售透支信任。检查：备货超 $500 前先上 10 个 listing 测点击。
2. **「利润藏在复购和搭配里」**——流量成本年年涨，单品利润会被吃掉。反例：节日爆款赚快钱不指望复购。检查：每个产品问"买了这个的人 30 天内还会买什么？"
3. **「平台是房东，你是租户」**——单一平台收入超 70% 就建第二渠道。反例：早期 all in 吃红利。检查：每月看一次收入结构。
4. **「颜值即转化」**（Etsy/POD）——主图 3 秒决策。反例：白牌标品拼价格。检查：上架前和 Top 10 并排放 3 秒测试。
