## 证据分级

- **A**：官方数据、可验证的公开财务数据
- **B**：当事人自述 / 访谈
- **C**：传闻、截图、"听说"级——允许收录，但必须标注

凡是"保证赚钱""稳赚"类表述，一律不收。
